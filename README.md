# Claims Automation with AI 

With vibe coding, this claims processing agent was created. The goal is to replicate how insurance claims processing works in real life, often times customers will forget to include pertinent information in their initial claim, so this interface accounts for the iterative nature of claims processing. Customers can see if their claims meet their policies or not in real time, without the hassle of waiting several days for an email from an insurance representative just asking for more information. 

"app.py" is version 1, the targer user is the claims representative of the insurance company 

"app2.py" is version 2, the target user is the customer themselves
